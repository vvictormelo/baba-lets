# Baba Lets

App de votação para o Baba Lets da empresa.

## Como usar

- Acesse o link e selecione seu nome
- Digite seu PIN
- Distribua as pessoas nos 6 potes (3 por pote)
- Confirme seus votos

## Admin

Acesse `/admin` com a senha configurada para acompanhar o progresso e revelar os resultados.
